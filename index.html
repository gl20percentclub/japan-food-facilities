クイックスタート

配信しているのは 全件CSV・都道府県別CSV・ベクトルタイル の3つだけです。 ベース URL は https://food.japan-facilities.com/api/。

1. CSV をダウンロードする（全件は約 540MB。1県だけなら都道府県別CSV が軽い）

curl -O https://food.japan-facilities.com/api/facilities-all.csv

# 東京都だけ欲しい場合（ファイル名は {都道府県コード}.csv）
curl -O https://food.japan-facilities.com/api/prefectures/13.csv

2. pandas で読み込む（URL 直指定でもいけます）

import pandas as pd

df = pd.read_csv('https://food.japan-facilities.com/api/facilities-all.csv')
# 那覇市の飲食店営業だけ抜き出す
naha = df[(df.city == '那覇市') & (df.business_type == '飲食店営業')]
print(naha[['name', 'address', 'lat', 'lng']].head())

3. 地図に出す（MapLibre GL JS・タイルサーバー不要）

map.addSource('facilities', {
  type: 'vector',
  tiles: ['https://food.japan-facilities.com/api/tiles/{z}/{x}/{y}.pbf'],
  minzoom: 6, maxzoom: 12,
  // 出典表示（source に入れると地図のアトリビューションに自動で表示される）
  attribution:
    '出典：<a href="https://gl20percentclub.github.io/japan-food-facilities/">Japan Food Facilities</a>'
    + '（<a href="https://gl20percentclub.github.io/japan-food-facilities/attribution.html">各自治体・厚生労働省のオープンデータを加工して作成</a>）',
});
// レイヤ名は "facilities"、属性は name / business_type / pref / city

CSV の中身

prefecture,city,city_raw,name,name_kana,business_type,address,lat,lng,geocoding_level,phone,license_no,license_date,expire_date,sources,licenses
沖縄県,那覇市,那覇市,ステーキハウス○○,ステーキハウスマルマル,飲食店営業,那覇市松山1-9-9,26.216965935,127.678060421,8,098-XXX-XXXX,第01202300556号,2023-12-07,2030-01-31,沖縄県食品営業許可・届出,CC BY 4.0

geocoding_level は付与した座標の精度（8=街区・地番 / 3=町丁目 / 2=市区町村 / 1=都道府県）。 元データに座標があった場合と補完できなかった場合は空です。

配信している形式

用途に合わせて3つから選べます。いずれも同じベース URL 配下の静的ファイルです。

形式パス用途
全件 CSV api/facilities-all.csv（約 540MB） pandas・BI ツール・DB 取り込みで分析する。全項目入り・BOM なし UTF-8 です。
都道府県別 CSV api/prefectures/{都道府県コード}.csv（例 13.csv＝東京都） 1県だけ必要なときに。列・内容は全件CSV と同じで、47都道府県すべて存在します。 ファイル一覧と件数は api/prefectures/index.json。
ベクトルタイル api/tiles/{z}/{x}/{y}.pbf（z6–12） 地図にそのまま重ねる。MapLibre GL JS から直接読めます。

収録データは地図ページでも確認できます。 地域や業種を絞りたい場合は、CSV をダウンロードしてフィルタしてください。 各列の詳細は README、 自治体ごとの収録状況は 収録状況一覧 を参照してください。

出典・ライセンス

本サービスは各自治体・厚生労働省が公開するオープンデータを加工・統合したものです。 利用時の出典表示は、ライセンスごとに求められる形式が異なります。

本データは、商用・非商用を問わず、アプリ、Webサービス、研究、分析、再配布などに利用できます。
利用・再配布する際は、次の出典を表示してください。 
出典：Japan Food Facilities（各自治体・厚生労働省が公開する食品営業許可オープンデータを加工して作成）
元データの出典・ライセンス一覧： https://gl20percentclub.github.io/japan-food-facilities/attribution.html
本データには複数の提供元によるデータが含まれており、各元データには、それぞれの提供元が定める ライセンスおよび利用条件が適用されます。詳細は 出典・ライセンス一覧を確認してください。
📢 出典表示文は 出典・ライセンス表示ページ にまとめています。
全 81 ソースの出典 URL とライセンス、およびそのまま貼れる出典表示文を一覧化しています。
緯度経度は本サービスが独自に付与した参考情報です。 自治体が提供しているものではなく、住所からのジオコーディング結果のため、実際の所在地と異なる場合があります。
本サービスは各自治体の公式サービスではありません。 内容の正確性・完全性・最新性を保証するものではないため、正式な情報は各自治体の公開情報をご確認ください。

データソースの追加も歓迎です

未収録の自治体は config/sources.yaml に 1 エントリ追加するだけで取り込めます。 バグ報告・データ品質の問題報告・ドキュメント改善も歓迎です。
